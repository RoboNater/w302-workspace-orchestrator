# Sample Project 1 — Data Processor

A lightweight data processing pipeline for CSV analysis.

## Overview

This project contains utilities for reading, processing, and analyzing CSV data files.

## Files

- `data-processor.py` — Main processor script
- `sample-project-1.code-workspace` — VS Code workspace configuration

## Usage

```bash
python data-processor.py data.csv
```

## Notes

- Python 3.8+
- No external dependencies
- Testing in progress
