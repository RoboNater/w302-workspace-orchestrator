# Sample Project 2 — Web Server

A minimal HTTP server for testing and development.

## Overview

This project provides a lightweight web server for serving static files and development testing.

## Files

- `web-server.py` — Main server implementation
- `sample-project-2.code-workspace` — VS Code workspace configuration
- `index.html` — Sample homepage

## Quick Start

```bash
python web-server.py 8000
```

Then visit: http://localhost:8000/

## Features

- Static file serving
- Custom request logging
- Configurable port
- Easy shutdown

## Requirements

- Python 3.7+
- No dependencies
